# LQR Gain Scheduler (C++)

Gain scheduler for hardware flight control. Loads the LQR gain schedule from CSV (generated by MATLAB `solveLQR.m`) and computes **u = -K(vel, h) * x** with bilinear interpolation.

## System Definition

- **State:** `x = [R, P, Y, Rdot, Pdot, Ydot]'` (roll, pitch, yaw angles and rates) [rad, rad/s]
- **Control:** `u = [delta1, delta2, delta3, delta4]'` (canard deflections) [rad]
- **Gain matrix:** `K` is 4×6, so `u = -K * x`

## Workflow

### 1. Generate CSV in MATLAB

Run `solveLQR.m` from the project root:

```matlab
>> solveLQR
Gains saved to lqr_gains.csv
```

This creates `lqr_gains.csv` with the gain schedule.

### 2. Build the C++ Code

Add to your firmware build:
- `GainScheduler.h` - Header with API
- `GainScheduler.cpp` - Implementation

Requirements: C++11, standard library only (no external dependencies).

### 3. Use on Target

```cpp
#include "GainScheduler.h"

// At init (once)
GainSchedulerHandle_t sched = GainScheduler_Create("lqr_gains.csv");
if (!sched) {
    // Handle error
}

// In control loop
float x[6] = {roll, pitch, yaw, roll_rate, pitch_rate, yaw_rate};  // [rad, rad/s]
float u[4];  // Output: canard deflections [rad]

if (GainScheduler_ComputeControl(sched, velocity_mps, altitude_m, x, u)) {
    // Apply u[0..3] to canard servos
}

// At shutdown
GainScheduler_Destroy(&sched);
```

## API Reference

### Create/Destroy

```cpp
GainSchedulerHandle_t GainScheduler_Create(const char* csvPath);
void GainScheduler_Destroy(GainSchedulerHandle_t* handle);
```

### Get Gains

```cpp
// Interpolated gains at (vel, h)
bool GainScheduler_GetGains(handle, velocity, height, &gains);

// Raw gains at grid index (for debugging)
bool GainScheduler_GetGainsAtIndex(handle, vel_idx, h_idx, &gains);
```

### Compute Control

```cpp
// u = -K(vel, h) * x
bool GainScheduler_ComputeControl(handle, velocity, height, x, u);
```

### Configuration Info

```cpp
GainSchedulerConfig_t config;
GainScheduler_GetConfig(handle, &config);
// config.vel_min, vel_max, h_min, h_max, num_vel, num_h, etc.
```

## CSV Format

Generated by `solveLQR.m`:

```
velocity,height,K11,K12,K13,K14,K15,K16,K21,...,K46
1.0,40.0,1.234e-01,5.678e-02,...
1.0,45.0,...
...
```

- First row: header
- Columns: `velocity` [m/s], `height` [m], then 24 K values (4×6, row-major, 1-indexed)
- Grid: velocity from 1 to 100 m/s (step 2.5), height from 40 to 500 m (step 5)

## Embedded without Filesystem

If your target has no file I/O:

1. Convert CSV to a C array at build time:

```cpp
// lqr_gains_data.h (auto-generated)
static const float LQR_VELS[] = {1.0f, 3.5f, 6.0f, ...};
static const float LQR_HS[] = {40.0f, 45.0f, 50.0f, ...};
static const float LQR_K_DATA[] = { /* all K values */ };
```

2. Modify `GainScheduler_Create()` to accept arrays instead of CSV path, or link the data directly into the scheduler.

## Notes

- Gains are clamped to table bounds (no extrapolation)
- Bilinear interpolation between grid points
- Thread-safe for read operations (single scheduler instance)
- Memory: ~24 floats × (40 vels × 93 heights) ≈ 356 KB for default grid
